## Подход к документированию

Требования, наблюдения интерфейсов, файловые свидетельства, результаты анализа исходного кода и результаты тестирования разделяются. Элементы, требующие подтверждения по первичным материалам, помечаются отдельно.

## Границы системы

Этот репозиторий содержит проектное описание логических подсистем ПОСС, ПОМС и ПОШ ВБД в рамках АРМ «Дешифратор». ПОСС/ПОМС/ПОШ ВБД следует сопоставлять с исходниками ModuleMobile, ModuleStationary и Printer / PassportPaint только там, где соответствие подтверждено. ППО «Территория» описывается здесь как внешний информационный контекст шлюза, а не как часть исходного кода АРМ.
